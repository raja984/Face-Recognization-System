# 🎓 Face Recognition Attendance System

A modern, animated attendance system built with **Python**, **OpenCV**, and **CustomTkinter**.

![Python](https://img.shields.io/badge/Python-3.9+-blue)
![OpenCV](https://img.shields.io/badge/OpenCV-4.9-green)
![CustomTkinter](https://img.shields.io/badge/CustomTkinter-5.2-orange)

## ✨ Features

- 📹 **Live camera preview** with real-time face detection
- 🎨 **Modern animated UI** — fade-in, hover, pulse, slide-in toasts
- 🔒 **Duplicate prevention** — rejects duplicate ID, name, OR face
- 📋 **Live attendance list** — see who's present today in real-time
- 🗓️ **Once-per-day marking** — no duplicate attendance on the same day
- 🚫 **Unknown face handling** — saves stranger snapshots automatically
